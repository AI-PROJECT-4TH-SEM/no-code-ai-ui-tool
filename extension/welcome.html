How to use

1
Click the ♿ extension icon in your Chrome toolbar on any page
2
Hit Scan This Page — results appear in ~20 seconds
3
Use ⚡ Apply Fix on each violation to patch the DOM instantly
4
Switch to 🖱 Drag tab to drag & drop elements on the page
5
Use 📐 Layout Inspector to click any element and inspect design principles
6
Switch to Themes tab to inject a live CSS theme on the page

Make sure your backend is running at localhost:3000.
Right-click any page and choose ♿ Scan this page for quick access.
