Action Type: moveElementStructural
Positions: before | after | append | prepend
Examples: Move images, buttons, spans, any element
```

### 2️⃣ ADD TEXT DYNAMICALLY
```
User: "Add 'Limited Time Offer' to all product titles"
Result: ✨ Text updates across all matching elements

Action Type: addTextContent
Modes: replace | append | prepend
Examples: Labels, badges, promotional text
```

### 3️⃣ WRITE ANY HTML
```
User: "Write a welcome banner at the top with text 'Welcome'"
Result: ✨ Complete HTML structure injected safely

Action Type: freeFormDomWrite
Modes: replace | append | prepend | before | after
Examples: Sections, banners, forms, navigation
```

```

## 🔧 HOW IT WORKS

### User Types Command
```
"Move the button below the form"
```

### Extension Sends to API
```
POST /api/assistant
{
  instruction: "Move the button below the form",
  url: "https://example.com",
  selectedElement: {...},
  html: "<full page HTML>"
}
```

### Cohere API Interprets
```
Using enhanced prompt with all new action types
Model: command-a-03-2025
Temperature: 0.3
Max Tokens: 800
```

### Returns Action
```json
{
  "type": "moveElementStructural",
  "selector": "button.primary",
  "targetSelector": "form.login",
  "position": "after"
}
```

### Extension Executes
```
Resolves elements
Moves button after form
Glows element (visual feedback)
Updates undo stack
Done! ✨
```
